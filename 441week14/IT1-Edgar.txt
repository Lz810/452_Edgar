##Question 5:
Answer:
Purpose Analysis
•	Client-side Scripting (e.g., JavaScript):
Runs in the user's browser to manipulate web page DOM elements and implement interactive logic. Its core goal is to optimize user experience (e.g., real-time form validation, dynamic page rendering).
•	Server-side Scripting (e.g., Node.js/Python):
Executes on the server to handle data processing, business logic, and resource management (e.g., database operations, user authentication). Its core goal is to ensure data security and stable execution of server-side logic.
Differences:
1.	Execution Environment:
o	Client-side: Browser (e.g., JavaScript).
o	Server-side: Server (e.g., Node.js).
Example:
// Client-side: Validate form input
document.getElementById('form').addEventListener('submit', (e) => {
  e.preventDefault();
  if (!document.getElementById('email').value) alert('Enter email');
});

2.	Data Security:
o	Client-side: Code is visible to users (potential security risks).
o	Server-side: Code runs on secure servers, protecting sensitive logic.
