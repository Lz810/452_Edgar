DOM (Document Object Model)
1.The DOM is a tree-like structure that represents the HTML or XML document. It allows JavaScript to dynamically access and manipulate the content, structure, and style of a web page. It is essential because it enables JavaScript to modify elements, respond to user interactions, and create interactive web pages.

2.document.getElementById("id")

document.querySelector(".class")

document.getElementsByTagName("div")

3.textContent returns or sets the plain text content of an element, ignoring HTML tags.

innerHTML returns or sets the HTML content of an element, including parsing and rendering HTML tags.

4.

const div = document.createElement("div");
div.textContent = "Hello World";
document.body.appendChild(div);
Events
1.An event is an action triggered by the user or the browser. 
Examples include:
click (when an element is clicked)
keydown (when a keyboard key is pressed)
submit (when a form is submitted)
2.addEventListener: Can bind multiple event handlers and supports the event's capturing and bubbling phases.
onclick: Can only bind one function and is an inline event handler (e.g., <button onclick="fn()">). It mixes HTML and JavaScript, making the code less maintainable.
3.event.preventDefault() prevents the default behavior of an event. For example, to prevent a form from refreshing the page after submission:
form.addEventListener("submit", (e) => {
  e.preventDefault(); // Prevent form submission from refreshing the page
  // Custom logic
});
Variables
1.

var: Function-scoped, can be redeclared, and is subject to variable hoisting. let: Block-scoped, cannot be redeclared, and does not have hoisting. const: Block-scoped, must be initialized when declared, and cannot be reassigned.

2.Using const or let is recommended because they provide block scope, which helps avoid variable pollution and accidental overwriting. They also make the code more predictable and maintainable.

3.The variable becomes a global variable (throws an error in strict mode).

4.const PI = 3.14;


Functions
1.A function is a reusable block of code that performs a specific task. Functions improve code reusability, readability, and modularity.

2.Function declaration: function fn() {} (hoisted, can be called before being defined). Function expression: const fn = function() {} (not hoisted, must be defined before being called).

3.A callback function is a function passed as an argument to another function and executed after a specific condition or operation.

4.

function greet(name) {
  return `Hello, ${name}!`;
}
Loops
1.for: Used when the number of iterations is known (e.g., iterating through an array). while: Loops as long as a condition is true (e.g., reading input until a certain condition is met). for...of: Used to iterate over iterable objects (e.g., arrays, strings).
2.break: Immediately terminates the entire loop. continue: Skips the current iteration and proceeds to the next one.
